## Project Overview

CampfireSongbookBuilder builds campfire songbooks from a CSV song list. It fetches or reuses cached lyrics/chords, cleans the text, and generates Word documents.

## Quick Reference

- **Tech Stack:** Python, pandas, requests, BeautifulSoup/lxml, lyricsgenius, python-docx, unittest
- **Entry Point:** `main.py`
- **Architecture Pattern:** Single-process CLI plus helper modules
- **Database:** None; file-based JSONL caches

## Getting Started

### Prerequisites

- Python 3.8+
- Genius API token
- Dependencies from `requirements.txt`

### Setup

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp data/config/config.example.json data/config/config.json
```

### Run Locally

```bash
python3 main.py --generate-from-cache
```

### Run Tests

```bash
python3 -m unittest discover -s tests -p 'test_*.py'
```
